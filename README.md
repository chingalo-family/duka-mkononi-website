# Duka Mkononi Website

Official marketing site for the Duka Mkononi shop management app (English + Swahili).

## Live Website

[https://chingalo-family.github.io/duka-mkononi-website/](https://chingalo-family.github.io/duka-mkononi-website/)

## Pages

| Purpose | English | Swahili |
|---------|---------|---------|
| Home | `index-en.html` | `index.html` |
| Privacy Policy | `privacy-en.html` | `privacy.html` |
| Terms & Conditions | `terms-en.html` | `terms.html` |

Also: `assets/` (app icon + product screenshots), `scripts/contact-form.js`

## Local Development

```bash
git clone https://github.com/chingalo-family/duka-mkononi-website.git
cd duka-mkononi-website
python -m http.server 8000
```

Open http://localhost:8000 (Swahili home) or http://localhost:8000/index-en.html

## Deployment

Pushes to `main` deploy automatically via GitHub Pages.
